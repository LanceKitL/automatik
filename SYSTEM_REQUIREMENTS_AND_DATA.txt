E.  API ENDPOINT REFERENCE BY MODULE

  Notation:
    [PUB] = Public access (no auth required)
    [USR] = Any authenticated user
    [CUS] = Customer role only
    [AGT] = Agent role only
    [ADM] = Admin role only

E.1  AUTHENTICATION & SESSION MANAGEMENT
----------------------------------------------------------------------

  Tables: users, access_tokens, user_profile

  METHOD  ENDPOINT                       ROLE     DESCRIPTION
  ------  ------------------------------ -------  ----------------------------------------
  POST    /auth/register                 [PUB]    Register new customer account.
                                                  Returns 201 on success.
                                                  Body: email, password, confirm_password,
                                                  full_name, phone
  POST    /auth/login                    [PUB]    Login with email + password.
                                                  Creates Flask session.
                                                  Returns user data on 200.
  POST    /auth/logout                   [USR]    Clear session. Returns 200 + redirect URL.
  GET     /auth/me                       [USR]    Current user profile + role info.
                                                  Returns user + profile fields (safe).
  POST    /auth/verify-email             [PUB]    Verify email via token from email link.
                                                  Query: ?token=<uuid>
  POST    /auth/forgot-password          [PUB]    Request password reset email.
                                                  Rate limited: 3/hr per IP.
  POST    /auth/reset-password           [PUB]    Reset password using token.
                                                  Body: token, password, confirm_password
  POST    /auth/resend-verify            [PUB]    Resend verification email.
                                                  Rate limited: 3/hr per IP.
  GET     /portal/access                 [PUB]    Magic-link login for customers.
                                                  Query: ?token=<uuid> → 302 redirect.

E.4  INQUIRIES & CHATBOT
----------------------------------------------------------------------

  Tables: inquiries, chatbot_logs, agent_tasks

  METHOD  ENDPOINT                       ROLE     DESCRIPTION
  ------  ------------------------------ -------  ----------------------------------------
  POST    /inquiries                     [PUB]    Create inquiry. Guests provide guest_name,
                                                  guest_email. Customers auto-linked.
  GET     /inquiries                     [ADM]    All inquiries. Filter: status, agent_id,
                                                  date range. Paginated.
  GET     /inquiries/my                  [CUS]    Own inquiries joined with vehicles.
  GET     /inquiries/<id>                [ADM/   Full detail + chatbot logs.
                                          AGT]
  PUT     /admin/inquiries/<id>/assign   [ADM]    Assign agent, set status=assigned.
  PUT     /inquiries/<id>/resolve        [AGT]    Resolve (agent must own inquiry).
  PUT     /inquiries/<id>/close          [ADM]    Close (only from resolved status).
  POST    /chatbot/message               [PUB]    Send message to AI chatbot.
                                                  Returns bot_response + intent_tag.
                                                  Gated by chatbot_enabled setting.
  GET     /admin/chatbot/logs            [ADM]    Chatbot logs. Filter: session_id,
                                                  user_id, intent_tag.
  GET     /admin/chatbot/logs/<id>       [ADM]    Single log entry.

  Intent Tag Taxonomy (intent_tag ENUM):
    Tag                Trigger Description
    ------------------ -----------------------------------------------
    price_inquiry      User asks about vehicle price/payment
    test_drive         User wants to schedule a test drive
    availability       User asks if a vehicle is in stock
    financing          Questions about loans or installment
    warranty           Warranty coverage questions
    service_booking    Service or maintenance scheduling
    document_request   OR, CR, or contract inquiry
    complaint          Dissatisfaction or issue report
    general_inquiry    Catch-all for unmatched polite queries
    unclassified       AI could not determine intent (fallback)

  <Frontend Data:>
